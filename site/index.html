Lisovyk — українська розкладка, з якою не треба перемикатися ні на англійську, ні на російську

Дужки, лапки, @, #, бектик і решта спецсимволів, а також російські э, ы, ъ — просто з української розкладки. Для Linux, без root-прав, за два кроки.

Встановити за два кроки ↓

Що ви отримуєте

  • Спецсимволи під рукою

    [ ] { } < > ; ' @ # ^ & ` ~
    Правий Alt і та сама клавіша, що в англійській розкладці: пальці вже знають, куди тягнутись. А \ та | набираються взагалі без модифікаторів.

  • Код, чати й запити до ШІ — українською

    `код`, [посилання](…), @згадки, #канали, блоки в потрійних бектиках і JSON набираються посеред українського речення, без зміни розкладки.

  • Російські літери без російської розкладки

    э, ы, ъ — правий Alt і українська літера, що звучить так само: е, и, ь. Цитату, прізвище чи назву можна набрати, не тримаючи в системі третьої розкладки.

  • Правильний апостроф і наголос

    Клавіша ліворуч від 1 дає літерний апостроф ʼ: слово лишається цілим, і подвійне клацання виділяє «пʼять» повністю. На ній же знак наголосу: «за́мок» чи «замо́к».

  • Нічого не треба вчити заново

    Усі українські літери, цифри й розділові знаки — на звичних місцях. Нове зʼявляється лише з правим Alt.

  • Чисте встановлення

    Без root і без змін у системних файлах: усе лежить у вашій теці налаштувань і прибирається однією командою.

Встановлення: два кроки

1

Виконайте скрипт

Він додає розкладку у вашу теку налаштувань. Root-права не потрібні, системні файли не змінюються.

curl -fsSL https://vovche.github.io/lisovyk/install.sh | bash

Спершу хочете подивитися, що всередині? Відкрийте скрипт або код на GitHub.

2

Увімкніть розкладку у своєму середовищі

Скрипт лише встановлює розкладку. Ваші джерела введення він не чіпає, тож додати Lisovyk до них треба самостійно.

GNOME

  1. Вийдіть із сесії та увійдіть знову. GNOME читає перелік розкладок лише під час входу, тому без цього Lisovyk у списку не зʼявиться.
  2. Відкрийте «Параметри» і перейдіть у розділ «Клавіатура».
  3. У блоці «Джерела введення» натисніть «Додати джерело введення».
  4. Введіть у пошуку Lisovyk, виберіть «Ukrainian (Lisovyk)» і натисніть «Додати».
  5. Перемикайте розкладки клавішами Super + Пробіл або значком у верхній панелі.

Стандартна «Українська» нікуди не зникає: можна тримати обидві розкладки й перемикатися між ними.

Інші середовища

Hyprland 
# ~/.config/hypr/hyprland.conf
input {
    kb_layout = us,ua
    kb_variant = ,lisovyk
}
niri 
// ~/.config/niri/config.kdl
input {
    keyboard {
        xkb {
            layout "us,ua"
            variant ",lisovyk"
        }
    }
}
Sway 
# ~/.config/sway/config
input type:keyboard {
    xkb_layout us,ua
    xkb_variant ,lisovyk
}

Потрібна сесія Wayland. Перевірено в GNOME на Ubuntu 26.04 та Fedora 44.
